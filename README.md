# Construworth Consult website prototype

Two design directions, built as static sites for client review:

- `round-1/`: Blueprint Ledger (light) with the QS Desk
- `round-2/`: refined direction with cost tools and a night-theme case study

Each folder is its own Vercel project (root directory = the folder, no build step).
Pages are marked `noindex`. Figures marked "illustrative" or "indicative" are placeholders.
